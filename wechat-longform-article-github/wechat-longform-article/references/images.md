# 配图作业单（真实图＋AI理解图）

这份文件是第3步"配图"的操作细则。目标：一篇长文里，真实图和AI理解图交替出现，真实负责可信，理解负责解释。

## 一、先出配图清单

写到一半才找图，必然出现"整篇同一种图"。动笔前先把清单排出来：

| 位置 | 要说明什么 | 类型 | 检索词 / prompt |
|---|---|---|---|
| 开篇 | 那天晚上的真实场景 | 真实图 | 小豆 公测 App Store 截图 |
| 第一章 | 产品到底长什么样 | 真实图 | 努比亚 NaviX Ultra 实拍 记者摄 |
| 第二章 | 演示与现实的落差 | 理解图 | 明亮阶梯 与 断裂长桥 对比 |
| 第四章 | 能力半径 vs 信任半径 | 理解图 | 两个同心发光圆环 |
| 第五章 | 锁住的第三方入口 | 理解图 | 走廊 多扇门 红色警示 |

规则：真实图 ≥ 1/2（必须过半），理解图 ≥ 1/3，其余位置用组件；每章至少2张图且真实图至少1张；连续两张不同类。

清单先按总量倒推：1万字以内≥16张（建议18–20），2–4.5万字≥24张（建议30+）。先把真实图的坑位排满，再用理解图补剩下的位置——顺序反了就会写成一整篇概念图。

真实图必须覆盖四类，缺哪类补哪类：

| 类别 | 检索词写法 | 例子 |
|---|---|---|
| 人物 | 人名 + 照片／演讲／本人主页 | 林俊旸 照片、张一鸣 演讲 |
| 现场／发布会 | 会议名 + 年份 + 现场／记者摄 | GTC 2026 现场、云栖大会 现场 |
| 产品／界面 | 产品名 + 实拍／界面／App Store | Qwen3.8-Max 官方发布图 |
| 报告／文档 | 报告名 + 封面／发布 | 斯坦福 AI Index 2026 封面 |

## 二、真实图检索

- 关键词组合：`产品名 + 实拍/发布会/界面/截图/记者摄/官方`。中文产品用中文词，海外产品用英文词。
- 一次至少取 3 个候选，逐条看：是不是这一代产品、有没有水印/裁切、清晰度够不够、有没有明显 P 图痕迹。
- 优先来源排序：权威媒体现场摄影 > 官方发布 / 发布会大屏 > 应用商店截图 > 厂商物料。
- 图注写清来源，例如 `图源：每日经济新闻 记者摄`、`图源：苹果 WWDC26 发布会`、`图源：App Store 截图`。

## 三、链接验证与落地

搜到的外链多有防盗链或 302 跳转，必须验证：

```bash
# 跟随跳转看真实响应
curl -sL -o /tmp/img -w "%{http_code} %{content_type} %{size_download}\n" "$URL"
```

能拿到 `200 image/*` 就下载压缩，再换成稳定链接：

```python
from PIL import Image
im = Image.open(path).convert('RGB')
w, h = im.size
im = im.resize((1200, int(h * 1200 / w)), Image.LANCZOS)
im.save(out, 'JPEG', quality=88, optimize=True)
```

上传后把 HTML 里的 `src` 全部替换成新链接，再跑一次可达性检查。交付时统一提示：**发布前在公众号后台重新上传这些图**。

## 四、AI 理解图 prompt 模板

固定三件套：**画什么关系 + 色彩与光影 + 不要文字**。

- 封面／氛围：`深夜书桌，手机在暖光里发亮，屏幕上浮起半透明的发光手掌与彩色光点；深蓝夜色与窗外灯海，冷暖对比强烈，色彩鲜艳饱和，电影感，不要任何文字。`
- 概念分界：`两个同心发光圆环，内圈小、外圈大，之间有多条彩色光线相连；深色背景，青蓝紫橙渐变，高饱和，极简有光泽，不要文字与数字。`
- 数据落差：`左侧整齐高耸的玻璃阶梯与明亮光束，右侧一条断裂崩塌的长桥，碎片悬浮，中间一道分界线；蓝金与暗红对比，戏剧化光影，不要文字与数字。`
- 权限／边界：`一条未来感走廊，数扇发光门，其中三扇挂锁并有红色警示光，一束蓝光停在门前；高饱和，深色调，电影级光影，不要文字。`

生成后先看一眼：图里有没有莫名文字、比例是否被拉伸、颜色是否发灰。不合格就重生成，不要凑数。

## 五、图注怎么写

- 真实图：来源 + 一句现场感。`图源：每日经济新闻 记者摄｜9 月 16 日开售当天，这台机器就摆在柜台上。`
- 理解图：一句判断，不写"概念示意图"。`外面那圈是它能碰到的世界，里面这圈是它能替你决定的事。`
- 禁止：`图为××`、`AI生成`、`示意图，仅供参考`。

## 六、常见坑

1. **型号错代**：把上一代产品图当这一代用。图注里写清型号与日期。
2. **水印与裁切**：带第三方水印的图不要用；截图裁掉状态栏里的个人信息。
3. **链接过期**：生成图与搜图的链接都可能带签名有效期，长文发布前统一重传。
4. **一图多用**：同一张图不要在两章里重复出现，宁可换一张。
5. **图多但无用**：每张图都要回答"它在替哪句话作证"。答不上来就删。
