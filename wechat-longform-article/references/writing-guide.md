# 写作指南：风格、结构与去AI味

本文件是写作阶段的详细参考。目标是让2–4.5万字读起来像"竹心一言"本人花了一周时间、带着个人判断写出来的原创深度文，而不是资料汇编或通稿。

## 一、文章结构

### 开篇（800–1500字）
用一个具体场景、一个人物、一个反差强烈的事实或一段对话切入，不要用"随着……的发展""近年来"开头。三段之内让读者知道这件事和他有关、值得花很长时间读下去。开篇结尾处自然亮出全文要回答的核心问题。

### 主体（按内容选2–4种推进方式交替使用）
- **现象层**：发生了什么，当事人怎么说，舆论场什么反应。
- **人物层**：把抽象议题落到具体的人——他的一天、他的选择、他的代价。
- **利益层**：谁在赚钱、谁在承担成本、链条怎么转、钱从哪来到哪去。
- **争议层**：把对立观点都摆出来，让双方用自己的话吵架，作者暂不站队或晚一点站队。
- **数据层**：用3–5个关键数字锚定规模和趋势，数字要带来源（平台名+机构名），但不贴链接。
- **历史层**：往前倒三年五年，这件事是怎么一步步走到今天的。
- **比较层**：和别的地区、别的行业、别的年代比。

### 结尾（800–1500字）
回到开篇的人物或场景，给出作者的判断或态度，但不要喊口号、不要升华到空洞的"时代""我们都"。可以留一个开放问题。最后是署名"竹心一言"。

### 章节配比参考（以3万字为例）
- 开篇 1500
- 背景来龙去脉 3000
- 现象与人物 6000（2–3章）
- 利益链/深度归因 6000（2章）
- 争议与多视角 4500（1–2章）
- 案例与故事 4500（1–2章）
- 趋势判断与落点 3000
- 结尾 1500

## 二、语言风格

1. **第一人称"我"在场**：写"我注意到""我翻了几百条评论后发现""我和一位从业者聊了很久"，而不是"据统计""有分析认为"。
2. **句子长短交替**：长句讲逻辑，短句砸重点。每出现一个三行以上的长句，后面跟一个短句。
3. **具体碾压抽象**：不说"价格很高"，说"一份卖到38块，比去年贵了11块"；不说"很多人"，说"评论区里点赞最高的三条都在骂"。
4. **直接引语制造现场感**：每章至少1–2处带引号的原话，可以来自采访、视频字幕、评论区、公开表态。引语要像人说的话，不要书面化。
5. **有判断、有偏好、有情绪**：作者可以愤怒、可以惋惜、可以保留态度，但不要端着。避免"客观中立"到没有观点。
6. **段落短**：手机阅读一段不超过4行，超过就拆。
7. **少用成语和排比**：最爱写"不仅……更……""一方面……另一方面……""值得一提的是"。能删就删。
8. **口语连接词**：用"说白了""问题在于""有意思的是""可你猜怎么着"代替"此外""然而""综上所述"。

## 三、去AI味：禁用词与改写

### 绝对禁用（出现即改）
AI、人工智能、大模型、语言模型、ChatGPT、GPT、机器人、机器写作、自动生成、AI生成、智能助手、本助手、作为AI、prompt、提示词、算法生成、AIGC。

### 高危元话语（暴露流水线，必须改写）
| 不要写 | 改写成 |
|---|---|
| 根据搜索结果 / 综合各平台信息 | 我翻遍了能找到的资料 / 我在几个平台来回刷了三天 |
| 数据显示 / 研究表明 | 我查到的一组数字是 / 某某机构在报告里写 |
| 有观点认为 / 有人指出 | 评论区一个高赞回答说 / 一位从业者告诉我 |
| 综上所述 / 总而言之 | 说白了 / 兜兜转转一句话 |
| 让我们一起来看看 | 我先从……说起 |
| 随着……的快速发展 | 直接写具体变化："这两年，……" |
| 在当今社会 / 众所周知 | 删掉，直接说事 |
| 本文将从以下几个方面 | 删掉，用故事开场 |
| 值得注意的是 / 不可否认 | 删掉，直接写那件事 |
| 首先 / 其次 / 最后（机械罗列） | 用小标题和过渡句代替 |
| 赋能 / 抓手 / 闭环 / 底层逻辑 | 换成正常人说的话 |
| 据悉 / 据了解 | "我查到""我听说" |
| 引发了广泛关注 / 引起热烈反响 | 写具体多少阅读、多少评论、什么反应 |

### 句式层面的AI味
- 连续三段都以"这"开头 → 换主语。
- 每段都是"总—分—总" → 砍掉一半的总结句。
- 过度对称（"A是……，B也是……；A有……，B也有……"）→ 打破对称。
- 空洞升华（"在这个时代，我们每个人都……"）→ 落到具体的人。
- 正确的废话（"这背后的原因是复杂的"）→ 直接写原因到底是什么。

### 自检三问
每写完一章问自己：
1. 这段话里有没有一个具体的人、数字或场景？没有就加。
2. 这段话能不能发在朋友圈而不显得像通稿？不能就改。
3. 把"我"换成"笔者/本文"还通顺吗？如果通顺，说明第一人称是假的，要改出真"我"。

## 四、长文节奏

- 每1500–2500字插入一个"呼吸点"：一个小故事、一段引语、一张配图、一个视觉组件、一个反问。
- 每章结尾留一个钩子，引向下一章（"可真正让我意外的，是后面发生的事"）。
- 重分析章节之后跟一个故事章节，重故事章节之后跟一个分析章节，避免读者疲劳。
- 数据密集段落之后，用一句大白话翻译给读者听（"说人话就是……"）。

## 五、配图与图注

- 图注不是图片说明，是正文的延伸。用一句话补充信息、制造悬念或表达态度。
- 图注示例（好）："这家开在巷子里的小店，菜单已经换了三回。"
- 图注示例（差）："图为某店铺照片。"
- 图注里不能出现"AI生成"等字样；网络搜图统一写"图源：某某平台"。

## 六、事实底线

- 所有数字、日期、人名、机构名必须来自第1步采集的真实素材，不得编造。
- 不同来源说法冲突时，写"关于这件事有两种说法"并都列出，不要只取一个。
- 预测性判断要标明是作者判断还是某某机构的预测。
- 宁可某一章短一些，也不要用水和编造填充字数。

## 七、视觉组件使用

模板提供以下组件，直接复制对应 HTML 片段改文字即可。**不要自行发明新样式**，保持全文统一。

| 组件 | 用途 | 使用频率建议 |
|---|---|---|
| 章节卡片标题 | 每个一级章节开头，浅底+左色条；可选胶囊标签放年份/关键词 | 每章1个 |
| 小节标题 | 章内分点，小色块+文字 | 每章2–4个 |
| 彩色标签段落 | 蓝=定义/概念，绿=解析/原因，橙=影响/意义，红=警示/反方 | 全文5–15次，勿连续堆砌 |
| 金句卡片 | 直接引语、值得反复读的判断 | 每章1–2个 |
| 数据卡片 | 3个以内关键数字并列对比 | 全文2–5次 |
| 时间线 | 事件发展脉络，纵向手机友好 | 需要梳理历程时用1次 |
| 要点列表 | 并列的判断/结论/清单 | 每章0–1组 |
| 配图+图注 | 场景、人物、信息图 | 每1500–3000字1张 |
| 分隔符 | 大段落之间的呼吸 | 章节之间或章内转折 |
| 参考资料 | 文末列来源（纯文字，不放链接） | 可选 |
| 作者署名区 | 头像+竹心一言+简介 | 文末固定 |

使用原则：
- **组件为内容服务**，不是每段都要套组件。连续3段以上纯文字时，用一个组件或配图打破节奏。
- 彩色标签段落适合"概念—原因—影响"的递进结构，但不要每段都加标签，否则像PPT。
- 数据卡片只放最有冲击力的3个数字，数字必须有来源。
- 时间线节点控制在3–6个，每个节点一句话说清发生了什么。
- 胶囊标签里放年份、章节序号或关键词，不要放长句。

## 八、配色选择

默认竹青配色适合大多数深度文。定稿后根据主题运行 `python3 scripts/apply_theme.py article.html <主题>` 一键换色，**不要手动改颜色**。

| 主题 | 适用内容 |
|---|---|
| bamboo（竹青，默认） | 文学、人物、深度调查、社会观察——拿不准就用它 |
| tech-blue（科技蓝） | 科技、互联网、AI、数码、商业分析 |
| warm-orange（暖橙） | 美食、消费、市井生活、烟火气、亲子 |
| forest（森林绿） | 自然、环保、健康、农业、户外 |
| elegant-purple（典雅紫） | 文化、艺术、教育、女性议题、书评 |
| china-red（中国红） | 时政、宏大叙事、节庆、历史、体育赛事 |
| ink-dark（墨黑） | 严肃评论、财经、法律、案件复盘 |
| sunset（日落橘） | 人物故事、情感、返乡、怀旧 |
| teal（青蓝） | 科普、新知、医学、商业新知 |
| rose（玫红） | 时尚、娱乐、情感、年轻向话题 |

蓝/绿/橙/红四个功能标签色是固定的，不随主题变化，用于"定义/解析/影响/警示"的语义区分。
