# wechat-longform-article

公众号长文的流水线——调研到原创长文，再到排版好的 HTML。

<sub>HTML · 可直接发布</sub>

---

## 工作流

公众号文章发布前走三步：

```
调研 → 写原创稿 → 渲染成带样式的 HTML
```

三步分开，意味着写作和排版不会缠在一起。你先以文本写稿，再把它放进渲染出移动端友好 HTML 的模板里，最后贴进公众号编辑器。

## 模板处理什么

- **移动优先**——段落、引用、标题层级都按窄屏阅读调过
- **可直接粘贴**——渲染出的 HTML 贴进公众号编辑器是干净的，不用重排
- **单页**——`template.html` 承载布局，写一篇新文章只要改内容，不用动模板
