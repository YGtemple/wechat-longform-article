# wechat-longform-article

公众号长文的流水线——调研到原创长文，再到排版好的 HTML。

<sub>HTML · 可直接发布</sub>

---

## 工作流

公众号文章发布前走三步：

```
调研 → 写原创稿 → 渲染成带样式的 HTML
```

三步分开，意味着写作和排版不会缠在一起。你先以文本写稿，再把它放进渲染出移动端友好 HTML 的模板里，最后贴进公众号编辑器。

## 模板处理什么

- **移动优先**——段落、引用、标题层级都按窄屏阅读调过
- **可直接粘贴**——渲染出的 HTML 贴进公众号编辑器是干净的，不用重排
- **单页**——`template.html` 承载布局，写一篇新文章只要改内容，不用动模板

## 配图政策

- **真实图 ≥ 1/2（必须过半）**：人物、新闻现场、发布会、产品与界面、报告封面，用图搜获取；每篇至少覆盖这四类。图注只描述画面场景，不写来源与媒体名。
- **AI 理解图 ≥ 1/3**：概念分界、能力半径、权限层级、时间脉络，用生图工具画，要求色彩饱满、无文字。
- **两类交替**：每 350–600 字一张；1 万字以内 ≥16 张（建议 18–20），2–4.5 万字 ≥24 张（建议 30+）；每章至少 2 张。
- 细则见 `references/images.md`。

## 文风红线

- **抬头不写字数**：标题下只留"竹心一言 ｜ 日期"。
- **去搬运感**：不写"两条短视频""视频里说"，导语必须是作者自己的判断或感受，出处只放文末参考资料。
- **交付前必审**：移动端视口逐屏渲染核验显示，再过一遍"吸引力五问"（标题冲突、导语观察、前三屏钩子、每屏停顿、结尾金句）。
