# 竹心一言 · 微信公众号长文创作 Skill

> 多平台调研 → 2–4.5 万字原创长文 → 微信兼容 HTML 排版 → 配图 → 自检交付，一条流水线完成。

一个面向 AI Agent（豆包 / 兼容 Skill 机制的助手）的可复用技能包。只需给出**主题、日期范围、风格倾向**，它会自动跨 10+ 平台搜集素材，以第一人称撰写署名「竹心一言」的微信公众号深度长文，输出可直接复制到公众号后台发布的单文件 HTML。

---

## ✨ 核心特性

- **🔍 多平台调研** —— 覆盖微博、知乎、小红书、抖音、B站、快手、豆瓣、贴吧、头条、澎湃、搜狗微信等 10+ 平台，视频内容自动提取字幕与逐字稿，支持登录态平台浏览器采集。
- **📝 超长原创写作** —— 正文 2 万–4.5 万字（最低 2 万字硬门槛），8–15 章节结构，第一人称叙事，有立场、有故事、有数据。
- **🎨 精美 HTML 排版** —— 全部样式内联，无需 CSS/JS，粘贴进公众号后台不丢样式；移动端 17px 字号、1.9 行高，阅读舒适。
- **🧩 22 类排版组件** —— 章节卡片、渐变章节标题、胶囊标签、五色标签段落、金句卡片、对话气泡、人物卡片、Q&A问答、红绿对比行、浅色旁注、多彩数据卡片、单数据大卡、时间线、双列对比、数字步骤、要点列表、关键词标签云、两种配图样式、两种分隔符等，开箱即用。
- **🎨 正文行内色彩** —— 每段必带色彩变化：多色荧光笔（黄/粉/蓝/绿/橙按语义轮换）、彩色数字大号强调、段首彩色引导词、核心句主题色放大、情绪词着色，杜绝密密麻麻一屏黑字。
- **🖼️ 智能配图** —— 全文≥10张图、每800–1800字一张，AI 生成色彩鲜艳的封面与氛围图为主，网络搜图补充真实实体；时间线、数据对比、流程步骤等优先用 HTML 组件实现，不占图片额度。
- **🎭 10 套主题配色** —— 竹青 / 科技蓝 / 暖橙 / 森林绿 / 典雅紫 / 中国红 / 墨黑 / 日落橘 / 青蓝 / 玫红，一键换色，适配不同选题。
- **🚫 不标注 AI 生成** —— 内置扫描器只拦截"本文由AI生成""作为AI助手"这类身份声明与AI拒答话术；AI/大模型/ChatGPT 作为讨论对象可正常出现，科技类选题无需回避。模板化元话语（"综上所述""根据搜索结果"）仅作风格提示，由作者按语境判断。
- **✅ 三重自检** —— 字数校验、AI 痕迹扫描、占位符残留检查，不达标不予交付。

```
wechat-longform-article/
├── SKILL.md                       # Skill 主文件：触发条件、工作流、硬性约束
├── assets/
│   └── template.html              # 微信公众号排版模板（内联样式，可直接套用）
├── references/
│   ├── writing-guide.md           # 写作风格、去AI味指南、组件与配色说明
│   └── platforms.md               # 10+ 平台清单与采集方法、素材整理模板
└── scripts/
    ├── word_count.py              # 中文字数统计（中文字符+英文词+数字串）
    ├── scan_ai_traces.py          # AI痕迹/元话语/占位符扫描器
    └── apply_theme.py             # 10套主题配色一键切换
```

## 🚀 安装

将 `wechat-longform-article` 文件夹放入你的 Skill 目录即可：

```bash
cd ~/.your-agent/skills        # 替换为你的 Skill 根目录
git clone https://github.com/<你的用户名>/wechat-longform-article.git
```

或直接下载本仓库的 ZIP 解压。目录结构需保持完整（`SKILL.md` 必须在文件夹根目录）。

## 📖 使用

安装后，在对话中直接用自然语言下达指令即可触发，例如：

> 用 wechat-longform-article，主题是「2026 年夏天县城咖啡价格战」，日期 2026-06-01 到 2026-08-20，写 3 万字，深度调查风格。

Skill 会按以下流水线执行：

1. **确认参数** —— 主题、起止日期、字数、风格、配色；日期写「XXX-XXX」会先追问。
2. **多平台调研** —— 并行检索 10+ 平台，视频提取字幕，登录态平台浏览器兜底，素材交叉验证。
3. **搭大纲** —— 8–15 章节，标注字数、配图与组件位置。
4. **配图** —— AI 生成色彩鲜艳的配图为主，全文≥10张、每800–1800字一张；HTML 组件实现时间线/数据卡/对比/步骤等。
5. **分章写作** —— 第一人称，逐章累计字数。
6. **HTML 排版** —— 套用模板组件，定稿后一键换主题色。
7. **自检交付** —— 字数、AI 痕迹、占位符三重校验，输出 `.html` 文件。

## ⚠️ 注意事项

- **微信兼容性**：模板全部使用内联样式，未使用 `<style>`、class、JS、`position`、浮动；如自行扩展组件，请同样使用内联 style，否则粘贴到公众号后台后样式可能被清洗。
- **图片**：AI 生成图返回的公网 URL 可直接引用；网络搜图可能存在防盗链，发布前建议在公众号后台重新上传。
- **事实底线**：所有数字、日期、人名、引语均来自真实采集素材，不同来源冲突时呈现多版本说法，不编造。
- **字数口径**：以中文字符 + 英文单词 + 数字串计，与 Word/WPS 中文字数统计一致。
